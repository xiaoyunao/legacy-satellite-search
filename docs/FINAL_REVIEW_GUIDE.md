# 最终集中人工审查

**旧版已撤下。** 本说明的填写流程将在 v14-final-2 验收通过后使用。

以 `results/v14/human_review/final_delivery_status.json` 的实际交付状态为准。
`final_ready_for_human_review=false` 时不要填写中间批次。

## 阶段一：一次集中判读

正式交付后，解压独立的 `anonymous_review.zip`，打开其中的
`anonymous_review.pdf`，填写同包的 `blank_review.csv`。
`page_index.csv` 和 PDF 书签用于连续翻页、定位。
可按书签分段阅读并保存进度，最后只封存一份完整判断表。
每个匿名编号填写一行；同一位置的不同来源和重要距离、尺度解都保留在该编号内。
重复的局部 alternative 标签只在各自来源内有效，备注请使用唯一页码或 evidence 编号。

`assessment` 允许四种值：

- `unassessable`：现有材料不足以判读；备注指出缺项。
- `artefact_or_background`：图像伪影、扩展源碎片或背景结构可以解释。
- `uncertain`：证据不足以明确判断。
- `follow_up`：测光与空间证据值得独立跟进。

`confidence`、`notes` 为可选文字。程序不预填任何人工等级。
一个或少数贡献源支配、不同假设表现不同等情况，可在备注中记录。
保留原始空白表，另存填写后的表，不修改已冻结 PDF、ZIP 或页码索引。

阶段一隐藏身份、绝对坐标、模型分数、成员概率及环境标签。
观察到的相对位置、测光误差、模型假设、原生 gr 图像和曝光范围保留。
这些面板来自同一成像，方法之间或多个颜色的一致不构成独立确认。
旧批次曾经公开的对象仍然保留；匿名化不会恢复这些对象的前瞻盲性。

## 阶段二：封存后揭示科学背景

全部匿名编号填完后，将实际填写表交回。程序核对发布哈希和编号覆盖，
封存用户原始判断，再揭示身份、全部 C 模式、去前三贡献源统计、
贡献源图像、观测条件、已知系统及复杂环境。
封存背景包含完整图像／C 诊断和逐原始生产记录绑定的已知环境附录；
空白环境字段表示未记录，不能据此认定附近没有已知结构。
同一套对象完成一次集中审查，不要求对后续中间批次反复评级。
身份键与第二阶段材料不在独立匿名 ZIP 内，不应提前打开。

`follow_up` 是人工跟进建议，不自动等于新系统、L1、独立确认或物理分类。
最终发现结论还需要已知对象核查和独立证据。

## 抽样与统计范围

冻结样本含 161 个生产审查单元以及两个弱源对照。
原 75 个对象、额外区域优先对象和分层随机审计均保留；真实身份与纳入概率
在封存后关联。空间单元是审查管理单位，不等同于物理恒星系统。
概率权重只支持对应 L0 抽样框内的人工标签比例，不能直接转成卫星完整度、
真实系统数或银河系种群丰度。科学选择函数的光度、距离和 PS1 响应限制另见
[第十四轮报告](../fourteenth_science_report.md)。
